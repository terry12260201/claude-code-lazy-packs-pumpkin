## 🔑 Vault 資料結構

本 vault 採用「**身份分流 + 原始資料永不動 + 知識庫由 AI 管理**」原則，源自卡帕西（Andrej Karpathy）LLM 筆記法，由三師爸 EP08 推廣，南瓜依個人多身份情境改造。

### 最外層：身份／類型分流

```
Pumpapa/
├── CLAUDE.md              ← 你正在讀的這份
│
├── 🟢 Clippings/          ← 外部抓回來的原始資料（Web Clipper 落點）
│
├── 南瓜虛擬科技/          ← 工作身份 1（VR 公司）
├── 智腦生醫/              ← 工作身份 2（HEKA）
├── 南瓜爸爸/              ← 個人／家庭身份
│
├── 🔵 知識庫/             ← AI 提煉產出（會持續成長）
├── 📊 週報/               ← 每週日 9:17 自動產出
├── 📋 Templates/          ← 範本檔（參考用）
├── 🖼️ Attachments/       ← 純圖片
└── _系統/                 ← 環境建置等系統文件
```

### 🟢 Clippings/ — 外部原始資料

- 瀏覽器 Web Clipper 抓進來的網路文章、YouTube 字幕、社群貼文
- **平的一層，不分子資料夾**（AI 重整時才分類提煉）
- **AI 永遠不修改這層的任何檔案**（只能改 frontmatter 的 status）

### 工作身份資料夾（南瓜虛擬科技、智腦生醫）

- 自己創作的原始資料：會議、SOP、提案、技術筆記、角色 Prompt
- **AI 不修改**（除非我明確說「幫我改 XXX 這篇」）
- 角色 Prompt 集合放 `南瓜虛擬科技/角色 Prompt/`（公司團隊用）

### 個人身份資料夾（南瓜爸爸）

- 個人學習、家庭、教會、出遊、美食、Terry 知識庫系統
- **AI 不修改**（除非明確指示）

### 🔵 知識庫/ — AI 管理的提煉層

- **唯一由 AI 管理、會修改、會新增的層**
- 每週日 9:17 由 AI 從 Clippings/ 與 三個身份資料夾 提煉重整
- 子資料夾：
  - `XR-創作/` — VR/AR/MR/3D 美術
  - `AI-工作流/` — Claude、Make、n8n、Apps Script
  - `教育與育兒/` — 親子、學習法、認知科學
  - `商業與創業/` — 創業、PM、商業模式
  - `個人學習筆記/` — 自我成長、學習脈絡
  - `_INDEX.md` — 知識索引（每週更新）
  - `_LOG.md` — 重整紀錄

### 📊 週報/

- 每週日由排程自動產出
- 命名格式：`YYYY-Www.md`（例如 `2026-W25.md`）
- 內容：本週新增筆記列表（含路徑超連結）、處理數量、知識庫更新、缺口分析、可深化的問題

### 📋 Templates/

- 6 份範本：Clipping、創作筆記、知識頁、週報、Web Clipper 設定指南、每週知識重整 Prompt
- **目前作為參考檔使用**（沒開 Obsidian 模板外掛）
- 需要時手動 Copy 或請 Claude 套用

### 🖼️ Attachments/

- **只放圖片附件**，MD 檔不要放這
- Obsidian 截圖、貼上的圖片預設存這

### _系統/

- 環境建置等「給未來的我看」的文件
- 例如：`_SETUP-Claude-Code-跨平台環境建置.md`

## 寫筆記的規則

新增或編輯筆記時：

1. **一律加 frontmatter**（title、date、tags 至少這三項）
   ```yaml
   ---
   title: 筆記標題
   date: 2026-06-17
   tags: [標籤1, 標籤2]
   source: [來源 URL，如果有]
   type: [clipping / creation / knowledge / weekly-report]
   ---
   ```
2. **標題用 H1** 作為筆記主標
3. **連結用 `[[wiki-link]]`** 串接相關筆記
4. **檔名**：可用中文，避免特殊字元 `\ / : * ? " < > |`
5. **圖片**：插入 vault 的圖片放 `Attachments/`

## AI 新增筆記時的分流規則

當我請 Claude 新增筆記，AI 必須先判斷類型：

| 我說的話的特徵 | AI 應該放到 |
|---|---|
| 「我剛看到一篇文章…」「這是網路抓的…」 | `Clippings/` |
| 「公司專案…」「這是聚陽案的…」 | `南瓜虛擬科技/[對應子資料夾]/` |
| 「HEKA…」「智腦的…」 | `智腦生醫/` |
| 「睿寶…」「Ann…」「個人的…」 | `南瓜爸爸/[對應子資料夾]/` |
| 「幫我整理…的重點」「把這幾篇歸納一下」 | `知識庫/[對應主題]/` |
| 「這禮拜的回顧」 | `週報/` |
| 環境設定、安裝紀錄 | `_系統/` |
| 模糊不清楚 | **問我，不要猜** |

## 每週知識重整（每週日 9:17）

每週由 Claude 自動執行「七步驟知識重整」：

1. 盤點本週新增筆記（Clippings + 三個身份資料夾）
2. 消化 Clippings → 提煉成 知識庫 對應主題
3. 提煉三個身份資料夾的新內容
4. Lint 連結檢查（缺失、孤兒、矛盾）
5. 更新 `知識庫/_INDEX.md` 與 `知識庫/_LOG.md`
6. 健康檢查（主題缺口、跨主題、孤立筆記）
7. 產出週報到 `週報/YYYY-Www.md`

詳細 Prompt 在 `Templates/每週知識重整-Prompt.md`。
