## 🔑 三層資料結構（核心原則）

本 vault 採用「**原始資料永不動、知識庫由 AI 管理**」的雙層架構，源自卡帕西（Andrej Karpathy）的 LLM 筆記法，由三師爸 EP08 推廣到台灣使用者：

### 🟢 Clippings/ — 外部原始資料

- 瀏覽器 Web Clipper 抓的網路文章、YouTube 字幕、社群貼文
- **AI 永遠不修改這層的任何檔案**
- 子資料夾：
  - `Clippings/Articles/` — 一般網頁文章
  - `Clippings/Videos/` — YouTube 字幕 / 影片筆記
  - `Clippings/Social/` — Twitter / Threads / Facebook 貼文

### 🟡 創作庫/ — 自己的原始資料

- 自己寫的、拍的、做的東西的原始檔
- **AI 也不修改這層**（除非我明確指示「幫我改 XXX 這篇」）
- 子資料夾：
  - `創作庫/南瓜虛擬科技/` — 公司專案、會議、SOP、技術筆記
  - `創作庫/南瓜爸爸/` — 個人、家庭、親子、學習、教會
  - `創作庫/角色 Prompt/` — AI 角色卡、人設、Prompt 集合
  - `創作庫/影片字幕/` — 我自己拍過的影片字幕（YouTube/Reels/Shorts）

### 🔵 知識庫/ — AI 整理過的、持續成長的層

- **唯一由 AI 管理、會修改、會新增的層**
- 每週由 AI 從 Clippings 與 創作庫 提煉重整
- 子資料夾：
  - `知識庫/XR-創作/` — VR/AR/MR/3D 美術
  - `知識庫/AI-工作流/` — Claude、Make、n8n、Apps Script
  - `知識庫/教育與育兒/` — 親子、學習法、認知科學
  - `知識庫/商業與創業/` — 創業、PM、商業模式
  - `知識庫/個人品牌/` — 品牌、內容策略、影音
  - `知識庫/_INDEX.md` — 知識索引（每週更新）
  - `知識庫/_LOG.md` — 重整紀錄

### 📊 週報/

- 每週日由排程自動產出
- 命名格式：`YYYY-Www.md`（例如 `2026-W25.md`）
- 內容：本週新增筆記列表（含路徑超連結）、處理數量、知識庫更新、缺口分析

### 📋 Templates/

- 筆記模板：Clipping、創作、知識頁、週報
- 新增筆記時優先用模板

### 🖼️ Attachments/

- **只放圖片附件**，MD 檔不要放這
- Obsidian 截圖、貼上的圖片預設存這

## 寫筆記的規則

新增或編輯筆記時：

1. **一律加 frontmatter**（title、date、tags 至少這三項）
   ```yaml
   ---
   title: 筆記標題
   date: 2026-06-17
   tags: [標籤1, 標籤2]
   source: [來源 URL，如果有]
   type: [clipping / creation / knowledge / weekly-report]
   ---
   ```
2. **標題用 H1** 作為筆記主標
3. **連結用 `[[wiki-link]]`** 串接相關筆記
4. **檔名**：可用中文，避免特殊字元 `\ / : * ? " < > |`
5. **圖片**：插入 vault 的圖片放 `Attachments/`

## AI 新增筆記時的分流規則

當我請 Claude 新增筆記，AI 必須先判斷類型：

| 我說的話的特徵 | AI 應該放到 |
|---|---|
| 「我剛看到一篇文章…」「這是網路抓的…」 | `Clippings/Articles/` |
| 「我拍了一支影片，字幕是…」「我寫了…」 | `創作庫/影片字幕/` 或 `創作庫/南瓜虛擬科技/` 或 `創作庫/南瓜爸爸/` |
| 「幫我整理…的重點」「把這幾篇歸納一下」 | `知識庫/[對應主題]/` |
| 「這禮拜的回顧」 | `週報/` |
| 模糊不清楚 | **問我，不要猜** |

## 每週知識重整（每週日 9:17）

每週由 Claude 自動執行「七步驟知識重整」：

1. 盤點本週新增筆記（Clippings + 創作庫）
2. 消化 Clippings → 提煉成 知識庫 對應主題
3. 提煉創作庫的新內容
4. Lint 連結檢查（缺失、孤兒、矛盾）
5. 更新 `知識庫/_INDEX.md` 與 `知識庫/_LOG.md`
6. 健康檢查（主題缺口、跨主題、孤立筆記）
7. 產出週報到 `週報/YYYY-Www.md`

詳細 Prompt 在 `Templates/週報模板.md`。
