# Claude Code 懶人包

> 每份懶人包都是一份可獨立執行的 Markdown 檔。把它丟給 Claude Code 桌面版或 CLI，Claude 會自動依步驟設定，遇到需要人手操作時暫停指示你。

---

## 使用方式

### 方式一：直接叫 AI 幫你裝（最簡單）

把對應的 MD 檔貼進 Claude Code 對話框，按提交。Claude 會依序執行：
1. 環境檢查（缺什麼自動安裝）
2. 安裝必要工具
3. 設定整合
4. 驗證可運作
5. 遇到需要手動操作時暫停告訴你

### 方式二：當教學文件看

每份 MD 都當作純文件閱讀也可以，步驟清楚、有指令範例、有踩坑紀錄、有常見問題排查表。

---

## 最低先備條件

使用任何懶人包之前，請確認：

- [ ] Claude 帳號已註冊（Pro 方案以上）
- [ ] Claude Code 桌面版或 CLI 已安裝
- [ ] 電腦能上網

## 設計重點

| 面向 | 設計選擇 |
|------|---------|
| 同步方案 | iCloud Drive（Apple 生態系跨 Mac/iPhone/Windows 三平台） |
| 平台覆蓋 | Windows + Mac 雙裝置平行對照 |
| MCP 設定 | `claude mcp add -s user` 官方指令（user scope） |
| 資料結構 | 提供兩種版本：三層版（單一身份）／身份分流版（多身份） |
| 自動化 | 每週日定時知識重整 + 自動週報 |
| 撰寫風格 | 每個步驟有 🖐️（手動操作）⚠️（踩坑紀錄）標記 |
